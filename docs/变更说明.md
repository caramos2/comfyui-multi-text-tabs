# 变更说明 · Multi-Text Tabs

## v1.1（2026-11-16 · 真机验收修复）

真机验收（ComfyUI v0.45.0 + 前端 1.58.5，浏览器实测）发现并修复三个真实缺陷。
三个都在前端，后端未改动，**工作流文件格式也没有变化**（v1.0 存的工作流可直接打开）。

### 修复 1（根因）：标签改动会写进「孤儿对象」

**现象**：点 ＋ 加不出标签（标签数恒为 1）、编辑区被清空、重命名不生效。

**根因**：前端把 `node.properties` 放在 Vue reactive 对象里
（`LGraphNode.get properties(){ return this._state.properties }`）。
写进去的是原始对象，读回来的是它的 reactive 代理：

    node.properties[KEY] = X      // 写入原始对象
    node.properties[KEY] === X    // false —— 读回来的是 reactive(X)，不是 X

v1.0 用 `===` 判断「状态有没有被换掉」，这个判断**永远为假**，
于是每次读状态都重新归一化并**整体替换** `properties[KEY]`。
一次操作里先后拿到两个不同的状态对象，前一个成了孤儿：
`addNewTab()` 里 `addTab()` 改的是那个孤儿，节点本身纹丝不动。

**修复**：不再用对象身份判断，改用藏在状态里的**标记（marker）**。
marker 是不可枚举属性，**不写进工作流文件**；
`state()` 永远返回同一个对象；外部替换（载入工作流 / 复制 / 撤销）
则因 marker 不匹配被自动识别并接管。

### 修复 2：双击重命名与右键菜单点不到

`attachEvents()` 在**捕获阶段**对 `dblclick` / `contextmenu` 调用了 `stopPropagation`，
事件在到达标签栏之前就被拦下，标签栏上的处理器根本收不到。

现改为：`pointerdown` / `mousedown` / `wheel` 仍在捕获阶段拦（防止拖动节点、缩放画布），
`dblclick` / `contextmenu` 改到**冒泡阶段**拦 —— 自己的处理器先跑完，再挡住画布。

### 修复 3：前端收不到「节点变了」的通知

`widget.callback` 在本前端默认为 `undefined`，原来的通知调用是空操作。现在：

- 文本与标签改动通过 `widget.value = ...` 走前端自己的 setter（`options.setValue` + callback）；
- 结构性改动（增 / 删 / 改名 / 复制 / 切换）用前端同款模式包裹：
  `graph.beforeChange()` → `canvas.emitBeforeChange()` → 改动 →
  `graph.afterChange()` → `canvas.emitAfterChange()` → `node.setDirtyCanvas(true, true)`。

## v1.0（2026-11-16）

## 新增

- ComfyUI 自定义节点 **Multi-Text Tabs**（`utils / text` 分类）：
  一个节点内收纳多份文本，顶部标签栏切换，一个编辑区，一个标准 STRING 输出。
- 后端 `nodes.py` / `__init__.py`：单 STRING 输入 `active_content`，单 STRING 输出 `text`，
  文本原样返回，不拼接、不 trim、不做提示词插值。
- 前端 `web/multi_text_tabs.js`：扩展注册（`beforeRegisterNodeDef` / `getCustomWidgets` /
  `nodeCreated` / `loadedGraphNode`），单 DOM widget 承载「标签栏 + 编辑区」。
- 前端 `web/multi_text_tabs_state.js`：**纯逻辑**状态机（无 DOM 依赖，可独立单测），
  负责标签集合的增删改切复制、ID 唯一性、数据校验与损坏修复、版本迁移。
- 前端 `web/multi_text_tabs.css`：节点内样式，全部以 `.mtt-` 前缀作用域隔离。
- 测试：`tests/test_nodes.py`（后端 8 项）、`tests/frontend/state.test.mjs`（状态机 26 项）、
  `tests/frontend/check_extension.mjs`（假 DOM 端到端 18 项）。
- 验收工作流：`Multi-Text Tabs 验收工作流.json`（已放入 ComfyUI 工作流库），
  含 Multi-Text Tabs → Preview as Text / Save Text 两条下游验证链路。
- `README.md`：安装、功能、兼容性、使用方法、故障排查、测试说明。

## 行为约定

- 默认只有一个 `Text 1`；点 ＋ 追加 `Text N`（编号不重复已用过的）。
- 切换标签前先把编辑区内容写回当前标签，**因此不会丢最后一个字**。
- 关闭标签：永远至少保留一个；关闭非空标签会给一次**撤销**机会。
- 重命名：双击标签就地编辑；复制：右键菜单，副本名为「原名 Copy」并立即激活。
- 标签过多时标签栏横向滚动，活动标签自动滚入可视区。
- 标签正文原样保留：换行、空格、中文、Emoji、`{weight:1.5}` 之类都不改写。

## 数据存放

| 数据 | 位置 | 是否进后端 |
|---|---|---|
| 全部标签标题与正文 | `node.properties.multi_text_tabs` | 否 |
| 当前活动标签 ID | `node.properties.multi_text_tabs.active_id` | 否 |
| 当前活动标签正文 | widget `active_content` | 是 |

工作流文件是唯一持久化来源，不使用 localStorage / sessionStorage。
